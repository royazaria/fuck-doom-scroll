# How to Install the F*CK Doom Scroll Extension

## Step 1: Make sure the app is running
Run `ScrollBlocker.exe` from the `dist/` folder (or `python -m app.main` if running from source).
You should see a small icon in your system tray (bottom-right of taskbar).

## Step 2: Load the extension in Chrome

1. Open Chrome and go to: `chrome://extensions`
2. Toggle **Developer mode** ON (top-right corner)
3. Click **Load unpacked**
4. Navigate to this folder and select the `extension/` folder
5. The extension "F*CK Doom Scroll" should now appear in your extensions list

## Step 3: Load the extension in Edge (optional)

1. Open Edge and go to: `edge://extensions`
2. Toggle **Developer mode** ON (bottom-left)
3. Click **Load unpacked**
4. Select the `extension/` folder

## Step 4: Test it

1. Open YouTube, Facebook, or Instagram
2. Scroll fast for a few seconds (the threshold is 2.5 minutes of active scrolling)
3. When you hit the limit — your screen will go fullscreen black with a 60-second countdown
4. After the countdown, you can scroll again

## That's it!

The app auto-starts with Windows after the first run. The extension stays loaded in Chrome/Edge.
